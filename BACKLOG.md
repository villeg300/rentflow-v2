## Après le MVP

Ces fonctionnalités ne doivent pas être développées avant la stabilisation du MVP :

* [ ] Notifications avancées
* [ ] Rappels automatiques
* [ ] Statistiques avancées
* [ ] Paiement en ligne
* [ ] Application mobile locataire
* [ ] Application mobile gestionnaire
* [ ] Portefeuille
* [ ] Analytics avancés
* [ ] Fonctionnalités multi-pays

## Règle

Une fonctionnalité ajoutée au backlog n'est pas automatiquement une fonctionnalité à développer.

Elle doit être analysée et priorisée avant son implémentation.

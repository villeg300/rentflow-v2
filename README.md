# RentFlow

RentFlow est une application de gestion locative destinée aux propriétaires et gestionnaires immobiliers.

Le projet vise dans un premier temps le marché burkinabè, avec une architecture permettant une évolution future vers d'autres marchés africains.

## Objectifs

RentFlow doit permettre de gérer simplement :

* les biens immobiliers ;
* les logements ;
* les locataires ;
* les contrats de location ;
* les loyers ;
* les paiements ;
* les retards de paiement ;
* les demandes de maintenance.

L'objectif principal est de réduire le travail administratif lié à la gestion locative.

## Architecture

RentFlow est organisé comme un monorepo :

```text
RENTFLOW_V2/
├── BACKEND/
└── FRONTEND/
```

### Backend

API REST développée avec Django et Django REST Framework.

### Frontend

Application web développée avec Next.js.

### Base de données

PostgreSQL.
